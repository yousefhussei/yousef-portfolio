Yousef Hussein - Data Analyst Portfolio

FILES
- index.html: main website
- style.css: design and responsive layout
- script.js: mobile menu, theme switch and reveal animations

HOW TO RUN
1. Put all files in the same folder.
2. Double-click index.html, or open it with Chrome.
3. Before publishing, replace YOUR_EMAIL@example.com and the LinkedIn # link in index.html.
